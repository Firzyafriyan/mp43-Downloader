# MP43 Downloader - YouTube MP3 & MP4 Real Downloader

Aplikasi web modern dan elegan untuk mengunduh video dan audio YouTube ke format **MP3** dan **MP4** yang 100% valid dan dapat diputar di Windows Media Player, VLC, smartphone, atau media player lainnya.

![MP43 Downloader Logo](assets/logo.png)

---

## 🚀 Panduan Cepat Menjalankan

Panduan lengkap cara menjalankan telah didokumentasikan di dalam folder **`docs/`**:
👉 **[Lihat Panduan Lengkap di docs/CARA_RUN.md](docs/CARA_RUN.md)**

### Cara Cepat (Paling Praktis):
- Klik dua kali (*double click*) file **[`run.bat`](run.bat)** di folder utama proyek.
- Peramban akan otomatis terbuka di `http://localhost:5000`.

### Atau Melalui Terminal:
```bash
python server.py
```
Lalu buka peramban di: **`http://localhost:5000`**
